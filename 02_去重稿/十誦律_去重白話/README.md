# 十誦律去重白話

以《十誦律》（說一切有部）為底本，同時以《四分律》（法藏部）、《五分律》（彌沙塞部）為對校本；凡兩律任一已有的內容視為重複並刪除，只留十誦律獨有或與兩律均實質不同之文。原文逐字迻錄，**九百四十九項悉附白話**。

| `十誦律_去重白話_合冊.md` | 全書：凡例、統計、目錄、六十一卷正文、附錄一～三 |

## 規模

- 底本正文 658,969 字（六十一卷）
- 保留 161,403 字（24.5%），949 項
- 白話 949 項全備，202,521 字
- 戒條與揵度部分（卷1～47）保留 10%～27%；毘尼增一與優波離問（卷48～61）保留 14%～88%——此兩部多為十誦律獨有之判例問答，比例高是文本結構使然。

## 使用

1. 先讀合冊「凡例」與「全書統計」。
2. 每項含：位置（底本段號）、四分律對照、五分律對照、差異說明、原文、白話。
3. 白話為編者所譯，以逐句對應為原則，術語保留原詞；考據仍以原文為斷。
4. 想知道某段為何刪除 → 合冊附錄一（逐卷刪略總表）。
5. 界限難定者 → 附錄二（存疑總表）。
6. 方法與限制 → 附錄三。
