## 如何使用

1. 先讀合冊本「凡例」與「全書統計」，了解取捨標準與各單位比例。
2. 欲知某段為何刪除，查附錄一該單位刪略表；欲知某項為何保留，看正文該項「差異說明」與三律對照。
3. 欲查故事材料，開《摩訶僧祇律_去重白話_獨有敘事.md》。
4. 引用時請附段號（如「摩訶僧祇律卷5，段37」），工作檔在 `_work/sengqi/`。
