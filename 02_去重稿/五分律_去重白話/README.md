# 五分律去重白話

## 使用

1. 先讀合冊本「凡例」與「全書統計」，了解判重口徑與各卷比例。
2. 正文每項含：位置、四分律對照、差異說明、原文、白話；凡「四分所無」之項，於四分律對照之後另增十誦律對照。
3. 想知道某段為何刪除，查合冊本附錄一（逐卷刪略總表）。
4. 界限難定者列於附錄二（存疑總表）；附錄三為上傳差異分析的核實報告；附錄四為方法與資料限制。

## 重要說明

- 原檔案（`五分律/`、`四分律/`）未改動；本稿是節本，不是取代原典的定本。
- 判重以「戒條／制度／事件」為單位，非以字句異同為準。
- 「十誦律對照」只用於消除「四分所無即五分獨有」的假性判定，不代全律之交叉校勘；其餘諸項與四分律既有對應，未另作十誦比對。
- 本資料夾《四分律》尼律單提法第一至八十六戒僅存戒條列表，緣起從缺；此部分之比對以戒條有無與內容異同為準。
- 《四分律》自恣揵度之一未收入本資料夾，卷十九自恣法之比對以其餘可得部分及全庫檢索為據。
- 白話為現代語譯，非學術定本；引用佛典原文，請以底本覆核。
