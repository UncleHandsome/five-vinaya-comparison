# 十誦律去重

以《十誦律》（說一切有部）為底本，同時以《四分律》（法藏部）、《五分律》（彌沙塞部）為對校本；凡兩律任一已有的內容視為重複並刪除，只留十誦律獨有或與兩律均實質不同之文。**本編不譯白話**（依指示）。

## 檔案

| 檔案 | 內容 |
|---|---|
| `十誦律_去重_合冊.md` | 全書：凡例、統計、目錄、六十一卷正文、附錄一～三 |
| `十誦律_去重_卷一至卷二十.md` | 比丘戒：波羅夷、僧殘、不定、尼薩耆、波逸提、悔過、眾學、七滅諍 |
| `十誦律_去重_卷二十一至卷四十.md` | 七法（受具足戒、布薩、自恣、安居、皮革、醫藥、衣）、八法、雜誦、雜法 |
| `十誦律_去重_卷四十一至卷六十一.md` | 雜法、尼律、毘尼增一、優波離問、五百／七百集法 |

## 規模

- 底本正文 658,969 字（六十一卷）
- 保留 161,403 字（24.5%），949 項
- 戒條與揵度部分（卷1～47）保留 10%～27%；毘尼增一與優波離問（卷48～61）保留 22%～94%——此兩部多為十誦律獨有之判例問答，比例高是文本結構使然。

## 使用

1. 先讀合冊「凡例」與「全書統計」。
2. 每項含：位置（底本段號）、四分律對照、五分律對照、差異說明、原文。
3. 想知道某段為何刪除 → 合冊附錄一（逐卷刪略總表）。
4. 界限難定者 → 附錄二（存疑總表）。
5. 方法与限制 → 附錄三。
