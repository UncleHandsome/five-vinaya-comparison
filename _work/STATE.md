## 四、數據流（改哪裡影響哪裡）

```
matrix_rows.json ──matrix_build.py──> matrix_built.json
                                            │
                          ┌─────────────────┼─────────────────┐
                     errata.apply      errata.apply      errata.apply
                          │                 │                 │
                  build_compare.py     matrix_md.py       fix_csv.py
                          │                 │                 │
                  對照本 MD（8 檔）      矩陣 MD            CSV
                          │
              ┌───────────┴───────────┐
        build_html.py            build_pdf.py
              │                       │
         05_網頁版/               06_PDF/
                                      │
                                build_tex.py → 07_PDF_LaTeX/
```

四分律原文與白話另有兩支輸入，只影響 `build_compare.py`：

| 模組 | 作用 |
|---|---|
| `align_sifen2.py` | 把《白話四分律》的「白話直譯」對到 `sifen/*.txt` 的 5,303 段，產出 `sifen_plain.json` |
| `sifen_src.py` | 讀 `sifen/` 與 `sifen_plain.json`，切「節」（戒／揵度子題）並供渲染 |
| `sifen_plain_qc.json` | 每節原文與所配白話之最高 cosine，低於 0.12 者標「暫從缺」 |

重跑對齊（僅在換白話稿時需要，約 20 秒）：

```bash
python _work/align_sifen2.py --build
```

差異說明進 `build_compare.py` 前先過兩支（順序固定）：

| 模組 | 作用 |
|---|---|
| `diff_rewrite.py` | 57 條逾 110 字、讀者反映難讀者的人工改寫稿（只調語序斷句，事實不動） |
| `diff_fmt.py` | 指代還原→標點統一→依句分條→**一律一行**→**分類語降為「異在」小字**→律名加粗（續條同律不重複加粗） |
| `errata.clean_title` | 標題同樣還原指代（內部呼叫 `diff_fmt.expand_refs`） |

**鐵律：改了上游必重跑下游**。一鍵：

```bash
python _work/rebuild_all.py        # MD→矩陣→CSV→HTML→PDF，約 50 秒
python _work/build_tex.py          # LaTeX 版，約 5 分鐘
```

## 五、勘誤機制（重要）

**不改 `matrix_built.json`**，一律在 `_work/errata.py` 覆蓋，存可追溯：

| 欄位 | 用途 |
|---|---|
| `title` / `diff_full` / `ref4` / `st` / `lv` | 整欄覆蓋 |
| `cells` | 五律欄（鍵名 `v4`/`v5`/`v10`/`vMK`/`vGU`） |
| `_sub` | `[(欄位, 原文, 新文)]` 局部替換 |
| `_append` | `[(欄位, 文字)]` 末尾追加 |
| `_note` | 勘誤理由（不渲染） |
| `ERRATA_POS` | 改判歸位 `{M-id: (篇號, 段號)}` |

渲染層的共用工具（都在 `errata.py`）：
- `clean_title(t, rid)` —— 去段號後綴、分類標籤、統一戒號為四分
- `cn2num(s)` —— 中文數字（支援「一百七十八」）
- `dedup_xref(x)` —— 補證欄括號去重

`build_compare.py` 另有：
- `fix_pos(r)` —— 僧祇稿「段X」自動補卷次
- `norm_seg(txt)` —— 引用格式（`013段8`→`013 段8`、清備忘殘留）
- `unlink_cross(txt, keep)` —— 分卷跨檔死鏈轉純文本
- `clip_orig()` —— 超長引文截斷（回退至句末標點）

## 十五、全站多關鍵字模糊搜尋（2026-11-05）

四類頁面（合冊、六分卷、矩陣、兩專題表）統一換用同一套檢索核心：

**語法**：空白分隔多詞（須全部命中）；`-詞` 排除；`"片語"` 要求連續。
**模糊**：先比正規化後的精確子串，不成則退回「子序列」匹配，
容漏字跳字（「摩埵」可中「摩那埵」）；正規化含去標點空白與異體字對照
（麁/麤、鉢/缽、著/着、牀/床、汙/污、脚/腳、㥲/瞋、柰/奈、㝹/兔、説/說、摺/襵）。
子序列跨度限 `needle.length*2`，免過散。

**各頁差異**：
- 對照本：多詞以「鄰近段落群」為一處（窗口 40 個文字節點），
  因卡片無包裹容器，不能要求同一節點含全部詞；精確命中排前。
- 矩陣、專題表：以「同一列」為單位（列即最小項），合理。
- 正規化結果快取於節點／列（`_n`、`_norm`），合冊 11 MB 首次約 0.2 秒。

**順手修二 bug**：
1. `go()` 只加 `.hitflash` 不移除舊的，逐處巡覽會累積多個高亮
   （測試因此量錯元素，誤判跳轉失敗）。改為先清全部再加。
2. 全站 CSS `scroll-behavior:smooth` 使多次位置校正被平滑動畫互相打斷，
   越滾越遠（實測偏差達 5 萬 px）。跳轉期間強制 `scrollBehavior='auto'`
   並用 `behavior:'instant'`；另以 rAF 監測目標位置，偏離即修正，
   連續 4 幀穩定或 6 秒為止，並於 `document.fonts.ready` 後補一次
   （字體載入會整頁重排）。

實測（合冊）：載入 2.4s；「摩那埵」244 處、「摩那埵 波逸提」27 處、
「摩埵」237 處（模糊）、「迦絺那 -四分」305 處。
