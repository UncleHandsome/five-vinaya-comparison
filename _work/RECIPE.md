# 校勘去重規格（根本說一切有部毘奈耶／摩訶僧祇律 → 對照《四分》《五分》《十誦》，保留者譯白話）

你是律藏校勘與白話翻譯助手。工作目錄：<PROJ>
凡本檔所列規則，一律嚴格遵守；工作單另指定本次處理之卷次、底本檔與輸出檔。

## 一、任務

以指定底本之該卷（或相鄰二卷）為範圍，逐段對照三部上座系律：《四分律》《五分律》《十誦律》。
凡文意重複者刪除，只保留底本獨有或與三律均有實質增異之內容，並將保留部分譯為白話（現代繁體中文）。

## 二、判重口徑

1. 比對單位是「戒條／制度／程序／事件／法數清單」，不是字句。
2. 三律中任一律有同一戒、同一制度、同一事件、同一法數，且內容實質相同 → 刪除。
3. 保留：三律俱無者；或同一戒／同一事件中，底本有可指認之實質增異——判罪輕重不同、程序羯磨不同、法數多寡或項目不同、關鍵人物／地點／數量／結局不同、或別具一段獨立情節。
4. 刪除：僅譯語、次第、修辭、詳略不同；同一情節之擴寫（人物出家、父母勸阻、乞食細節等）；名相異稱而範疇相當；戒條本文、犯相逐條、開緣、四眾得罪等套語。
5. 每項須能以一句話講清差異；講不清者列「存疑」，不入保留。
6. 每項只摘「含差異之最小連續段落」；跨段引用標段號，段間缺口標「（中略：段X～Y）」。
7. 對三律而言，底本屬「同部系後出而細衍」者（如根有律之重頤、廣釋）多為詳略不同，刪；屬新增判例、新增羯磨、新增限制者，留。

## 二之三、保留比例（以字數計，不含「敘事抽取」）

- 《根本說一切有部毘奈耶》：目標 8%～20%。超過 25% 須自行覆核，刪去同事件之詳寫類。
- 《摩訶僧祇律》：目標 25%～45%。此律屬大衆部，與上座三部戒相、判數、犍度次第多所出入，保留率高乃正常；但仍不得以「譯語不同」為保留理由。超過 50% 須覆核。
- 比例只作自查之用，不得為湊比例而多刪或少刪；每項之去取一律以上述口徑為準。

## 三、對照方法

1. 先讀底本該卷，再讀工作單指定之四分律對照檔。
2. 必要時以 Grep（或 Read）在三個全庫查證，人名、地名、數量、制度名詞皆可檢：
   - 《四分律》：`_work/sifen/`（000～074 篇檔，每檔內「段N：」編號）
   - 《五分律》：`_work/wufen/`（vol01～vol30，段號同上）
   - 《十誦律》：`_work/shisong/`（vol01～vol61，段號同上）
3. 「五分律」「十誦律」之對照亦須寫出檔名＋段號＋一句引文；律部不同，三律中查得二者即可判為重複。
4. 律名與人名異譯極多（如 苾芻＝比丘、波羅市迦＝波羅夷、僧伽伐尸沙＝僧殘、窣吐羅底也＝偷蘭遮、波逸底迦＝波逸提、泥薩祇＝尼薩耆、室羅伐城＝舍衛城、逝多林給孤獨園＝祇樹給孤獨園、薄伽梵＝世尊／佛、鄔波離＝優波離、鄔波難陀＝跋難陀）。異譯不算差異，須比內容。
5. 若三律俱查無對應，必須寫「三律遍查未見」並列查詢詞（每律至少二個，或總列二至四個關鍵詞）。

## 四、譯文體例

1. 白話逐句對應原文，不增不減，不補情節、不加評論。
2. 術語（波羅夷、僧殘、羯磨、布薩、自恣、安居、衣界等）可保留，首次出現可以括號簡註。
3. 人名、地名、職名照原文；偈頌譯成整齊現代句。
4. 全文繁體，不用簡化字。

## 六、硬性校驗（自行完成後再回報）

1. 引文逐字：每條引文必須能在我給你的底本檔中逐字找到（不得改字、不得補字、不得以今字替代、不得摘句成自撰之語）。**以 Read／Grep 取得該段後複製貼上，不可憑記憶重打**；簡化字（如「犹」）絕不得混入引文或白話。
2. 段落覆蓋：保留項＋刪除表＋敘事抽取須覆蓋本次範圍之全部段號，不得有段號兩邊皆漏，亦不得重複收錄同段。
3. 白話齊備：每個保留項都要有「- 白話：」欄，且覆蓋該項原文每一句。
4. 摘要回報 200 字內：保留項數、比例、敘事抽取項數、最重大差異。

## 七、本生、譬喻、長篇敘事之抽取（各律皆適用，根有律尤重）

《根本說一切有部毘奈耶》多將本生、譬喻、長篇敘事附於戒條之下，動輒數千言。此類文字若三律俱無，**不得逕行刪除**，一律抽入輸出檔之「## 敘事抽取」節，另冊收錄；主體（保留項）只留其法律、制度、斷罪部分。

1. 判定：該段為故事（本生＝「我昔為…」、譬喻＝「如…時」、長篇敘事＝有完整情節起訖者），且不影響該戒之斷罪要素。
2. 三律俱無者 → 列入「敘事抽取」；三律任一有者 → 依第二節刪除，並在其中一句標明對應。
3. 抽取項目格式：

```
### N. 故事之名（本生／譬喻／敘事）
- 所屬：卷N·某學處／某犍度
- 位置：段X～Y（字數約 NNN）
- 三律對照：遍查未見＋查詢詞
- 要旨：二至三句自撰摘要（不逐字譯）
- 原文：
  > 首句、末句各引一段（各不逾 40 字），中略標「（中略：段X～Y）」
- 全文收錄：（僅當該敘事原文 ≤ 600 字時）逐字引全文，並附白話；逾 600 字者此欄寫「長篇，未譯，留指針」
```

長篇之原文由 `_work/extract_narr.py` 依「位置」所記段區間自底本整段抽出，**勿由人工抄錄**（人工抄錄易生訛字與簡形）。若本事只占某段之前半或後半，在「位置」內註明（如「段40 前半，至『隨汝意坐』止」），抽取器即於該處斷取；未註明者全段錄出，其帶出之判文、制文由抽取器逐條標明。

4. 「要旨」屬自撰文字，不得掛「原文」之名；原文欄只容逐字摘抄。
5. 主體保留率與敘事抽取之字數分開計算，各自列於「## 統計」。
6. 抽出之後以 `_work/qc_narr.py` 覆核另檔：甲——標「逐字抽出」者須與底本該段全段相同（或依自註於首段、末段截斷）；乙——未標抽出之節引須為底本之連續子串；丙——檔內凡例自報之引文行數須與實測對帳。
