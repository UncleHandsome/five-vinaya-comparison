# 五部律交叉比對

以《四分律》為軸，對校《五分律》《十誦律》《摩訶僧祇律》《根本說一切有部毘奈耶》四部，
逐條比對戒條、制度、法數、事件之異同。

**線上閱讀**：<https://unclehandsome.github.io/five-vinaya-comparison/>
（對照本與異同矩陣，可跳轉、篩選、搜索）

## 成品導讀

### 讀律：五部律差異對照本

以四分律七十五篇為綱，2,124 項差異全部歸位。每篇有「篇旨」述其內容，
項多之篇另有可折疊目錄；全篇按「節」切分（前三十卷以戒條為節，一戒一節；
卷三十一至六十以緣起事件為節，一節一事，凡段首作「爾時」「時有」「佛在」者即為新事之始，
共 839 節），節首標戒名／揵度名與事由（如「藥揵度（五）　顛狂比丘食生肉飲血」），
段號範圍另註於節題下，並附四分律原文與白話二摺疊塊，
**預設收起**——不需白話者逕讀差異，不礙瀏覽。每項有「差異」「本稿原文」「白話」「他部對照」。

- `五部律差異對照本.md` —— 合冊，392 萬字
- `五部律差異對照本_卷一至卷十.md` 等六檔 —— 按四分律卷次切分，便於對讀
- `五部律差異對照本_四分所無與歸併組.md` —— 第二部（四分所無 657 項）與第三部（歸併九組）單獨成檔

讀法：讀四分律至某篇某戒，翻至同篇同節，先看篇旨，再展開四分原文與白話，然後依段號看差異。

### 查證：五部律綜合異同矩陣

2,124 列，每列一項，五欄記各律「有／無／未比」。

- `五部律綜合異同矩陣.md` —— 可讀版
- `五部律綜合異同矩陣.csv` —— 可匯入表格軟體

### 方法：兩份報告

- `五部律交叉比對_整合報告.md` —— 方法、量化、碰撞結果、勘誤
- `五部律交叉比對_總規劃.md` —— 最初的工作規劃

開 `index.html` 即入。共十二頁：

| 頁 | 內容 |
|---|---|

| `五部律開遮持犯表.html` | 附錄六：657 列差異導向表 |

對照本：左側篇目樹（按卷折疊），白話折疊／展開，滾動時目錄高亮，可切換寬屏。
側欄另有<strong>目錄過濾</strong>（輸入篇名／戒名即篩）、<strong>摺疊狀態記憶</strong>、
<strong>拖曳調寬</strong>與<strong>收起／喚出</strong>；分卷前後、回目錄、展開收合與跳項號
集中為<strong>底部固定工具區</strong>，捲目錄時不消失（另有「↻ 更新」可破快取）。窄屏改為 ☰ 抽屜。
矩陣：五律欄以 ✓／✗／— 呈現，支援狀態、主稿、層級三重篩選與全文搜索。

全站快捷鍵：<code>Ctrl+K</code> 或 <code>/</code> 聚焦站內檢索（各頁自動指向該頁搜尋框）；
<code>Ctrl+F</code> 保留給瀏覽器原生查找、
<code>F3</code>／<code>Shift+F3</code> 前後巡覽命中處、<code>Alt+N</code> 收起或喚出側欄。
對照本檢索可切「全部／僅標題・項名／略白話・原文」三種範圍，結果附篇節脈絡與項號、
支援載入更多、近期檢索與律學名相同義詞提示。

### PDF（`06_PDF/`）

A4、內文 12pt 仿宋、行距 1.45、邊距 14–15mm，一頁約 1,200–1,600 字。
標題用微軟雅黑。每冊有封面與目錄頁。

> **PDF 不入版控（2026-11-06 起）**：歷次重建的 43–44 MB 合冊在 `.git` 內累積成
> 1.4 GB，已改寫歷史移除（149 → 135 commits，`.git` 1.4 GB → 39 MB；
> 現 pack 約 40 MB、`.git` 目錄約 68 MB）。兩目錄仍在本機，`.gitignore` 排除之；
> 重建用增量工具（推薦）：
> `python tools/pdf_jobs.py --plan` 先看哪些冊要重跑，
> `python tools/pdf_jobs.py` 只重建有變的分卷（多路並行，合冊預設延後），
> `python tools/pdf_jobs.py --include-full` 定稿時連合冊一起，
> `--force` 全量。指紋存 `_work/_pdf_jobs.json`；改 HTML／CSS／JS 不會動到 PDF。
> 底層仍可 `python _work/rebuild_all.py`、`python _work/build_tex.py --full`、
> `python tools/build_lean.py` 全量重建。改寫前的備份已於同日刪除。

> **字體之選**：正文用仿宋（FangSong），標題用微軟雅黑（Microsoft YaHei）。
> 曾試思源宋體（Noto Serif SC），然其為可變字體（VF），Chrome 打印時只取默認
> 實例 `ExtraLight`，字細而發虛，`font-weight` 與 `font-variation-settings` 皆不生效；
> 改用仿宋後筆畫清晰，且嵌入字體較小（同一內容比較，合冊可省約四成）。
>

> 較頁碼穩定——重排後頁碼會變，項號不變。

### 精簡版（`08_PDF_精簡/`）

抽去全書白話與每節所附的四分律原文，只留篇旨、節題、本節差異一覽、差異條列與本稿原文。
原稿 11.1 MB／2,611 頁，精簡後 4.1 MB／1,078 頁（Chrome 版 31.6 MB），頁數減約六成。

| 檔 | 說明 |
|---|---|
| `五部律差異對照本_精簡_Chrome.pdf` | Chrome 版，31.6 MB／1,078 頁 |
| `五部律差異對照本_精簡_LaTeX.pdf` | LaTeX 版，4.1 MB／1,364 頁，有頁碼、書籤 |

另有 **七冊分卷**，Chrome／LaTeX 各一套，分卷範圍與完整版相同（卷一至卷十、
卷十一至二十一、卷二十二至三十、卷三十一至三十七、卷三十八至四十九、
卷五十至六十、四分所無與歸併組），檔名如
`五部律差異對照本_精簡_卷一至卷十_Chrome.pdf`、`…_LaTeX.pdf`。

> 閱讀與引用用 LaTeX 版（有頁碼、書籤）；要頁數少、緊湊打印用 Chrome 版。

## 命名說明

1. **「毗」與「毘」通用**，本工作區統一作「毘」（如 `根本說一切有部毘奈耶`）。
2. 各去重稿凡例中所稱「本資料夾 `五分律/`」等，今在 `01_原文/` 下。
3. 成品中所稱「見各稿去重合冊《十誦律_去重白話》」等，今在 `02_去重稿/` 下。

   同名同級。引用時請指明部分，如「《五分律_去重白話》正文卷14」。

## 重新生成

對照本由 `_work/build_compare.py` 生成，數據源為 `_work/matrix_built.json`。
重跑前確認以下三檔為最新：

- `_work/matrix_built.json` —— 2,124 項原始數據
- `_work/_locate.json` —— 四分歸位結果
- `_work/originals_index.json` —— 各項主稿原文索引

輔助模組：

- `_work/norm_ref.py` —— 引用格式規範（`四分 014 段75` 一類）
- `_work/section_intro.py` —— 75 篇篇旨
- `_work/errata.py` —— 勘誤表（對照本、矩陣、CSV 共用，避免三者不一致）

> 活躍腳本（含附錄與專題表工具）共 **25** 支，詳見 `_work/ARCHIVE.md`；
> 其餘 130 支為歷史批次，2026-11-06 起自版控移除但**留在磁碟**（它們以
> `__file__` 定位 `_work`，搬進子目錄會斷路徑），可由 `_work/script_map.json`
> 或改寫前的備份分支還原。

網頁版與 PDF 另行生成。**建議用一鍵重建**，它按依賴順序跑完七步，
避免出現「PDF 比 Markdown 舊」的情況：

```bash
python _work/rebuild_all.py             # 全部（約 1.5 分鐘）
python _work/rebuild_all.py --no-pdf    # 略過 PDF（約 10 秒）
python _work/rebuild_all.py --only=1,2  # 只跑指定步
```

七步依次為：對照本 MD → 矩陣 MD → 矩陣 CSV → 對照本 HTML → 矩陣 HTML →
PDF 分卷 → PDF 合冊。

單獨跑某一步亦可：

```bash
python _work/build_compare.py           # 對照本 MD
python _work/matrix_md.py               # 矩陣 MD（套 errata）
python _work/fix_csv.py                 # 將勘誤套用至 CSV
python _work/build_html.py              # 對照本 HTML
python _work/build_matrix_html.py       # 矩陣 HTML
python _work/build_pdf.py               # PDF 分卷
python _work/build_pdf.py --full        # 另出合冊
python tools/build_lean.py              # 精簡版（去白話、去四分原文）兩版 PDF
```

需 pandoc 3.x、Chrome（Chrome 版 PDF）、TeX Live（LaTeX 版 PDF）。

外部工具路徑可用環境變量指定：`CHROME_PATH`（Chrome 可執行檔）、
`TEXBIN`（TeX 的 bin 目錄）。未設時自動查找 PATH，或回退至 Windows 默認位置。

PDF 由 Chrome headless 打印，CSS 見 `build_pdf.py`。
