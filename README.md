# 五部律交叉比對

以《四分律》為軸，對校《五分律》《十誦律》《摩訶僧祇律》《根本說一切有部毘奈耶》四部，
逐條比對戒條、制度、法數、事件之異同。

**線上閱讀**：<https://unclehandsome.github.io/five-vinaya-comparison/>
（對照本與異同矩陣，可跳轉、篩選、搜索）

## 成品導讀

### 讀律：五部律差異對照本

以四分律七十五篇為綱，2,124 項差異全部歸位。每篇有「篇旨」述其內容，
項多之篇另有可折疊目錄；全篇按「節」切分（前三十卷以戒條為節，卷三十一至六十以揵度子題為節，
共 576 節），節首標段號範圍與戒名／子題名，並附四分律原文與白話二摺疊塊，
**預設收起**——不需白話者逕讀差異，不礙瀏覽。每項有「差異」「本稿原文」「白話」「他部對照」。

- `五部律差異對照本.md` —— 合冊，387 萬字
- `五部律差異對照本_卷一至卷十.md` 等六檔 —— 按四分律卷次切分，便於對讀
- `五部律差異對照本_四分所無與歸併組.md` —— 第二部（四分所無 657 項）與第三部（歸併九組）單獨成檔

讀法：讀四分律至某篇某戒，翻至同篇同節，先看篇旨，再展開四分原文與白話，然後依段號看差異。

### 查證：五部律綜合異同矩陣

2,124 列，每列一項，五欄記各律「有／無／未比」。

- `五部律綜合異同矩陣.md` —— 可讀版
- `五部律綜合異同矩陣.csv` —— 可匯入表格軟體

### 方法：兩份報告

- `五部律交叉比對_整合報告.md` —— 方法、量化、碰撞結果、勘誤
- `五部律交叉比對_總規劃.md` —— 最初的工作規劃

### PDF（`06_PDF/`）

A4、內文 12pt 仿宋、行距 1.45、邊距 14–15mm，一頁約 1,200–1,600 字。
標題用微軟雅黑。每冊有封面與目錄頁。

| 檔 | 頁數 | 大小 |
|---|---:|---:|
| 合冊 | 2,067 | 33.7 MB |
| 卷一至卷十 | 335 | 6.8 MB |
| 卷十一至卷二十一 | 384 | 7.4 MB |
| 卷二十二至卷三十 | 228 | 4.6 MB |
| 卷三十一至卷三十七 | 167 | 2.9 MB |
| 卷三十八至卷四十九 | 339 | 5.5 MB |
| 卷五十至卷六十 | 266 | 4.3 MB |
| 四分所無與歸併組 | 356 | 6.6 MB |

> **字體之選**：正文用仿宋（FangSong），標題用微軟雅黑（Microsoft YaHei）。
> 曾試思源宋體（Noto Serif SC），然其為可變字體（VF），Chrome 打印時只取默認
> 實例 `ExtraLight`，字細而發虛，`font-weight` 與 `font-variation-settings` 皆不生效；
> 改用仿宋後筆畫清晰，且嵌入字體較小（同一內容比較，合冊可省約四成）。
>
> Chrome 版無頁碼與書籤（打印之限）。引用時請用項號（如 `D-0450`），
> 較頁碼穩定——重排後頁碼會變，項號不變。

- **書籤**：PDF 打開即展開章節樹，可跳轉
- **頁眉**：左側書名

## 命名說明

1. **「毗」與「毘」通用**，本工作區統一作「毘」（如 `根本說一切有部毘奈耶`）。
2. 各去重稿凡例中所稱「本資料夾 `五分律/`」等，今在 `01_原文/` 下。
3. 成品中所稱「見各稿去重合冊《十誦律_去重》」等，今在 `02_去重稿/` 下。
4. **去重稿合冊的卷標題（`## 卷N`）在正文、附錄一（刪略理由）、附錄二（存疑未決）各出現一次**，
   同名同級。引用時請指明部分，如「《五分律_去重白話》正文卷14」。

## 重新生成

對照本由 `_work/build_compare.py` 生成，數據源為 `_work/matrix_built.json`。
重跑前確認以下三檔為最新：

- `_work/matrix_built.json` —— 2,124 項原始數據
- `_work/_locate.json` —— 四分歸位結果
- `_work/originals_index.json` —— 各項主稿原文索引

輔助模組：

- `_work/norm_ref.py` —— 引用格式規範（`四分 014 段75` 一類）
- `_work/section_intro.py` —— 75 篇篇旨
- `_work/errata.py` —— 勘誤表（對照本、矩陣、CSV 共用，避免三者不一致）

> `_work/` 有 187 個 `.py`，其中僅以下十個為活躍：
> `rebuild_all`、`build_compare`、`matrix_md`、`fix_csv`、`build_html`、
> `build_matrix_html`、`build_pdf`、`errata`、`norm_ref`、`section_intro`。
> 餘為一次性腳本，記錄各稿比對過程，僅供追溯，不保證可重跑。

網頁版與 PDF 另行生成。**建議用一鍵重建**，它按依賴順序跑完七步，
避免出現「PDF 比 Markdown 舊」的情況：

```bash
python _work/rebuild_all.py             # 全部（約 1.5 分鐘）
python _work/rebuild_all.py --no-pdf    # 略過 PDF（約 10 秒）
python _work/rebuild_all.py --only=1,2  # 只跑指定步
```

七步依次為：對照本 MD → 矩陣 MD → 矩陣 CSV → 對照本 HTML → 矩陣 HTML →
PDF 分卷 → PDF 合冊。

單獨跑某一步亦可：

```bash
python _work/build_compare.py           # 對照本 MD
python _work/matrix_md.py               # 矩陣 MD（套 errata）
python _work/fix_csv.py                 # 將勘誤套用至 CSV
python _work/build_html.py              # 對照本 HTML
python _work/build_matrix_html.py       # 矩陣 HTML
python _work/build_pdf.py               # PDF 分卷
python _work/build_pdf.py --full        # 另出合冊
```

需 pandoc 3.x、Chrome（Chrome 版 PDF）、TeX Live（LaTeX 版 PDF）。

外部工具路徑可用環境變量指定：`CHROME_PATH`（Chrome 可執行檔）、
`TEXBIN`（TeX 的 bin 目錄）。未設時自動查找 PATH，或回退至 Windows 默認位置。

PDF 由 Chrome headless 打印，CSS 見 `build_pdf.py`。
