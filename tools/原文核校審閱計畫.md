> 版本：2026-11-04 初稿　｜　適用範圍：全書六十卷、七十五篇、D 1,458／S 657／矩陣 2,124 列
> 配合工具：`tools/verify_integrity.py`（結構）、`tools/audit_content.py`（內容，本次新增）

---

## 零、為什麼要換一種審閱方式

截至本計畫之前，本書已歷二十一轮外部校閱。累計指摘逾一百五十條，真正改到內容者不足二十處。原因不在校閱不認真，而在**方法**：那些意見多是「推測某個詞會被誤譯」「某個制度應該要有」，而不是「我查過底本，此處原文作某」。事後逐條 grep 的結果是——校閱所引的「原文」常常全庫 0 見。

反過來看，凡是**給得出可 grep 字串**的指摘，命中率極高：

| 輪次 | 可核字串 | 結果 |
|---|---|---|
| 十六 | `得偷蘭。遮見相便求` | 底本句讀確誤，已正 |
| 十六 | `與病人言：與汝自恣` | 囑授自恣主客確反，已正 |
| 十二 | `大三臘` | 白話確誤，已正 |
| 十八 | `知客與庫頭` | 時代錯置，已正 |
| 二十一 | `明相出` | 譯對了但**無定義**，已補判準 |

所以本次審閱改為**由內向外、以原文為錨**：不再等外部清單，而是自己把每一條差異拆回它聲稱依據的原典字句，逐環回查。前二十一輪最大的資產不是那些改動，而是累積的「不改理由」——本計畫把它制度化為審閱台帳的必要欄位。

**與既有自檢的分工**：`verify_integrity.py` 查結構（HTML 閉合、項號連續、錨點、三書項數、分卷銜接），已全綠；它查不出「這句差異說錯了」。本計畫補的正是內容層。

## 二、證據鏈：一條差異從哪裡來，要回到哪裡去

```
五部原典 01_原文/<部>/卷*.txt
    │  逐字迻錄（凡例三）
    ▼
findings 白話稿 125 檔 ── extract_originals.py ──> originals_index.json
    │  提取
    ▼
matrix_rows.json (2,124) ── matrix_build.py ──> matrix_built.json
    │  errata.apply（覆蓋，不改母表）
    ├── build_compare.py ──> 對照本 MD ──> build_html.py ──> HTML
    ├── matrix_md.py ──> 矩陣 MD ──> build_matrix_html.py
    └── fix_csv.py ──> 矩陣 CSV
```

**每一張差異卡片有五個可回查點**，審閱就是讓這五點互相對讀：

| # | 回查點 | 應回到哪裡 |
|---|---|---|
| ① | 本稿原文 | 所屬律原典（該項所從出之律） |
| ② | 四分對照（`ref4`） | 四分律原典／`sifen/` 段級切片 |
| ③ | 他部對照（`ref5`／`ref10`／僧祇／根有） | 對應部原典；僧祇、根有之引文另由 `originals_index.json` 供應 |
| ④ | 差異說明（`diff_full`） | ①②③ 的綜合；每一斷言都要能指到某句原文 |
| ⑤ | 五欄狀態（`v4`–`vGU`）＋`st`／`lv` | ①②③ 的有無；「未比」不得讀成「無」 |

任一點與原典不符，或五點彼此不相容，即記入台帳。

## 四、五道關卡

### 關一　引文回查（Citation Readback）— 全檢，2,124 項

**目標**：確認每一句引文都真的出自它聲稱的那一部、那一段。

**判準（四級）**

| 級 | 意義 | 處置 |
|---|---|---|
| 甲 | 逐字命中，段次亦合 | 通過，記台帳 |
| 乙 | 兩端命中、中間「……」為合法節引 | 通過，記省略位置 |
| 丙 | 未命中但可解釋（組字式 `[木*奈]`、異體 `麁／粗`、底本句讀如「得偷蘭。遮」、引自他部池） | 記理由，不改 |
| 丁 | 未命中且無合理解釋（誤引、張冠李戴、段次錯） | **改 `ref*` 或對照欄** |

**自動化**：C1 已能撈出 186 筆；其餘 89% 自動通過。人工只處理這 186 筆。
**特別注意**：底本自身有誤時（如「聽作尸」），**原文不改**，只在白話加校記——這是本書一貫的「存底本之真」。

### 關二　原子斷言查核（Assertion Verification）— 高風險全檢＋分層抽樣

**目標**：把 `diff_full` 拆成可單獨證偽的「原子斷言」，每條指派到原文位置核。

**拆解規則**（詳附錄一）：法數、罪名、人名、否定、比較、程序、時限，七類。

**高風險全檢池**（優先順序）：

1. C1B 的 37 筆假性「遍查未見」候選
2. C2 的 27 筆「四分無」而 `v4=有`
3. 所有含**法數**的斷言（「舉八種」「凡五法」「十誦別為九種」）——最容易算錯
4. 所有含**罪名層級**的斷言（波羅夷／僧殘／偷蘭遮／波逸提／突吉羅）——最容易張冠李戴
5. 標題與 `diff_full` 主張相反者
6. 前二十一輪已改過的 116 條勘誤——**回讀一次**，確認沒有被後續重建覆蓋

**判準**：每一斷言要能回答三問——「原文哪一句支持它？」「支持的是全部還是部分？」「有沒有反例？」

**最常見的病**：把「無此判語」寫成「無此制」。例如 M-0007「四分律無此判語」是對的（四分的確沒有那句判語），`v4=有` 也對（四分有捨戒之制）。**兩者不矛盾，但讀者會讀成矛盾**。處置不是改資料，是改寫法：「四分有捨戒之制，惟未立此判語。」

### 關三　敘述—狀態一致性（Narrative–Cell Consistency）

**目標**：差異說明、標題、五欄、`st`／`lv` 四者不能各說各話。

**必查三類**

1. **「未比」之別白**：`vMK` 1,521、`vGU` 1,885 記未比，而差異說明若提及該部（C3 現 3 筆），讀者會以為「僧祇無」。處置：在凡例六補一句「未比即未比，非謂無」，並在卡片該部對照欄補「未比」二字；**不改五欄資料**。
2. **狀態 A／D 之界**：第十二輪已查明 206 個 D 項泰半是「本稿有而他部無」，與凡例「本稿較他部為略」不盡合。凡例已加「須辨」。本次不再逐項改標籤（會製造新的不一致），只確認凡例文字仍足以覆蓋。
3. **層級 `lv`**：抽樣核「戒條／制度／事件／法數」是否與該項實質相符；改 `lv` 會動分組，非必要不改。

### 關四　可讀性與體例（Readability）— 含重寫

**可量測判準**

| 指標 | 門檻 | 現況 |
|---|---|---|
| 單條分條字數 | ≥12 字 | 67 條未達（C6） |
| `diff_full` 字數 | 25–400 | 9 條過短、2 條過長（C5） |
| 一句內律名數 | ≤3 | 待量 |
| 指代詞（「本律」「兩律」「其」） | 差異說明中應為 0 | 凡例九稱已覆核，本次抽驗 |
| 「遍查未見」贅語 | 同項重複出現應合併 | 892 見，待量 |
| 分條是否割裂引文 | 不得以「；」起頭 | C6 已納入 |
| 高頻術語有無定義 | 見附錄三 | 10 個未定義 |

**重寫的五種觸發條件**（不是所有不順都要重寫）

| 碼 | 條件 | 動作 |
|---|---|---|
| R1 | 斷言與原典相反 | **重寫 `diff_full`** |
| R2 | 引文張冠李戴 | 重寫對照欄 |
| R3 | 只羅列同異、未說「所異何在」 | 補寫結句（非重寫） |
| R4 | 分條割裂語意、律名指代不清 | 重組分條 |
| R5 | 標題與 `diff_full` 主張不符 | 改標題（**須複驗目錄與錨點**） |

**建議的改寫骨幹**（供重寫時一致）：

> 所異在〔X〕，不在〔Y〕。〔A 律〕……；〔B 律〕……。故〔結論〕。

第一句先界定爭點，中間兩句各自給原文位置，末句收束。避免「不同」「有異」一類空話，也避免把「未比」寫成「無」。

**「不改」也算完成**：凡判定「可改可不改」者，一律記入台帳並寫明理由，避免下次又被當新問題提出——這是前二十一輪最耗時的地方。

### 關五　白話段對位（Vernacular Alignment）

前幾輪踩過三種病，本次全書掃一次：

| 病 | 案例 | 檢查法 |
|---|---|---|
| 段次錯繫 | `007-11` 的「判決原則」實屬第一不定 | 節首白話首句是否與該節原文首句相應 |

| 整段重複 | 040 曾被指重複，實為 1 見 | 句級去重 |

**注意**：`sifen_plain.json` 是**段級鍵**（`007-11`），不是節級；移段要用 `fix_text_1104.PLAIN_MOVE`，補段用 `PLAIN_ADD`，不可直接改 JSON（重跑 align 會覆蓋）。

## 五、分層執行：全檢 × 抽樣 × 逐篇輪讀

2,124 項 × 5 個查核點 ≈ 一萬次查核，不可能全人工。分四層：

| 層 | 範圍 | 方式 | 規模 |
|---|---|---|---|
| **L0** | 全 2,124 項 | 全自動：`audit_content.py` 八碼 | 349 待核入帳 |
| **L1** | 高風險池 | 人工逐條回原文（關二優先序 1–6） | 約 200–300 項 |
| **L2** | 其餘 | 按 `canon × lv × st` 分層，每層抽 10%，另加 5% 純隨機 | 約 200 項 |
| **L3** | 75 篇 | **逐篇輪讀**：先讀該篇四分原文，再對讀同篇所有差異卡片與白話 | 6 批 × 12–13 篇 |

**L3 是「整個翻閱原文」的落點**，也是唯一能查出「卡片各自都對、合起來卻漏了一整件事」的方法。每批固定動作：

1. 讀該篇四分原文一遍（不先看卡片）
2. 記下自己認為「值得立差異」的點
3. 對讀卡片，看有無「該立未立」「不該立而立」「立了但說反」
4. 檢查篇旨、節題、白話段對位
5. 記台帳

抽樣發現錯誤率 >5% 時，該層**擴為全檢**。

## 六、五級判定與審閱台帳

| 判定 | 意義 | 後續 |
|---|---|---|
| **確** | 回原文無誤 | 記台帳，不改 |
| **誤** | 與原典不符 | 進勘誤批次 |
| **疑** | 底本兩可、或諸家異說 | 記「存疑」，加按語不改判 |
| **可改** | 無誤但不好讀 | 進潤色批次（關四） |
| **不改** | 有理由維持現狀 | **必填理由** |

**台帳 CSV 欄位**（`審閱台帳.csv`）：

```
批次, 篇號, 項號(D/S/M), 檢查碼, 層(L0-L3), 回查點(①-⑤),
原文位置(部/卷/段), 現文摘要, 判定, 理由, 處置,
errata鍵, 改動欄位, 複驗結果, 審閱日期
```

「不改」的理由要寫到能擋住下一輪同樣的指摘，例如：「`聽作尸` 為大正藏原字，後文『閉戶』可證其當作戶；存底本之真，白話已加校記。」

## 七、改動紀律（鐵律，沿用既有）

7. 上游一動，必跑 `python rebuild_all.py --no-pdf`（約 12 秒）。**PDF 依囑待定稿才建**。
8. 每批結束：`verify_integrity.py` + `audit_content.py` 複驗 → commit → 再重建一次讓版本戳對上最新提交。
9. **改標題、狀態、層級前先想影響面**：標題動目錄與錨點，狀態動分組，層級動分節，D 號一動則全書交叉引用盡棄。

## 附錄一　原子斷言拆解規則

| 類 | 抽出正則（示意） | 查核動作 |
|---|---|---|
| 法數 | `(舉|凡|立|列|別為|分為|有)[一二三四五六七八九十\d]+(種|法|事|類|戒|人|日|夜|歲|指|錢)` | 回原文數一遍；注意「三分白」是序數不是分數 |
| 罪名 | `波羅夷|僧殘|偷蘭遮|波逸提|突吉羅|尼薩耆|滅擯|摩那埵|別住` | 核罪名與部派（僧祇「越比尼」不可逕等同突吉羅） |
| 人名 | 專名表（沓婆摩羅子、蓮華色、偷羅難陀、須達多…） | 核該律緣起人物，諸部常有移花接木 |
| 否定 | `遍查未見|無此|不載|未見|不立|無有|所無` | 區分「無此制／無此語／未比」三層 |
| 比較 | `所異在|不同|而…(無|有)|惟|但` | 確認兩造各自有原文位置 |
| 程序 | `白二羯磨|白四羯磨|三諫|與欲|結界|布薩|自恣` | 核人數門檻與先後次序 |
| 時限 | `明相出|七日|十日|五日|安居竟|迦絺那衣已捨` | 明相非日出；「已捨」是特權期滿非送衣 |
